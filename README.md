# 书页之间 · 个人读书笔记展示站

## 文件说明

- `index.html` —— 首页：自我介绍 + 最新 3 本读书笔记卡片
- `books.html` —— 书籍列表页：全部书籍卡片，点击进入详情
- `detail.html` —— 读书笔记详情页：根据 URL 参数 `id` 显示对应书籍的读后感与摘抄
- `about.html` —— 关于我页面：个人介绍、网站用途、联系邮箱
- `css/style.css` —— 全站样式（白底、响应式、卡片悬浮、淡入效果）
- `js/data.js` —— 书籍数据（所有笔记内容都写在这里）
- `js/main.js` —— 页面渲染逻辑（动态生成卡片和详情）

## 如何修改内容

- 增加/修改书籍：编辑 `js/data.js` 中的 `books` 数组。
- 修改个人介绍或邮箱：编辑 `about.html`。
- 修改样式：编辑 `css/style.css`。

## 如何运行

直接双击 `index.html`，用浏览器打开即可。所有页面通过相对链接跳转，无需服务器。
